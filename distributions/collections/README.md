# Skill Collections

This directory is generated by `scripts/refresh_skill_collections.py`.

- `example-skills.txt` lists top-level skill directories (one per line).
- `by-category/`, `by-complexity/`, `by-purpose/`, tier and governance lists are derived from skill frontmatter.

Regenerate after adding/removing skills:

```bash
python3 scripts/refresh_skill_collections.py
```
