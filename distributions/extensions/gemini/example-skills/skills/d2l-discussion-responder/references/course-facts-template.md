# Course facts and verification

Use this checklist for the course identified by the user. Fill values only from
current course materials or the instructor's explicit direction. Keep a filled
checklist in the authorized session or a user-requested private destination;
never write live course identifiers or student material into this skill.

## Source discipline

Record the source location and verification time for each factual claim. Useful
sources can include the current syllabus, assignment page, content tree,
instructor announcement, and a course definition supplied by the user. No
particular repository or course-management engine is required.

If sources disagree, identify the conflict and ask the instructor which current
instruction governs. Do not silently prefer an old syllabus, a cached value, or
a generated course definition over a newer instruction. Recheck time-sensitive
facts before posting. Preserve an explicit `unverified` or `conflicting` state
until the evidence resolves it.

## Checklist

- Map the name a student uses to the exact assignment label and unit.
- Verify the due date, time, and time zone; distinguish due dates from availability
  windows or late-work cutoffs.
- Locate the material in the current Content tree and copy its displayed label.
- Read the assignment requirements before saying that a template, upload,
  research source, or completed draft is required.
- Confirm that navigation aids or applications are actually available in this
  course before recommending them.
- Keep names, grades, student posts, and private correspondence out of the
  checklist. It records course logistics only.

## Blank session template

```markdown
Course and term: <confirmed in the current LMS session>
Verification time: <date and time with time zone>

| Claim needed for reply | Observed value | Current source | Status |
|---|---|---|---|
| Assignment label and unit | <exact label> | <source location> | unverified |
| Due date and time zone | <value only after checking> | <source location> | unverified |
| Material location | <displayed module/section> | <source location> | unverified |
| Assignment requirement | <observed requirement> | <source location> | unverified |

Conflicting sources: <describe without guessing a resolution>
Instructor clarification needed: <specific missing fact>
```

Change a row to `verified` only after inspecting its source. A placeholder or a
plausible example is never a course fact.
