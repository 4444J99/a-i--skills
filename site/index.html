a-i--skills

An open catalog of agent skills: self-contained SKILL.md modules that teach AI coding agents how to do specialized work in a repeatable way.

View the repository on GitHub →
176skills (165 catalog + 11 plugin)
12categories
4runtimes: Claude Code, Codex, Gemini CLI, Claude API

What's inside

  • Skill library: creative, data, development, documentation, education, integrations, knowledge, professional, project-management, security, specialized, and tools skills.
  • Tooling: Python scripts that validate frontmatter and links, generate a machine-readable registry, build per-runtime bundles, and serve skills over MCP.
  • Plugins: two Claude Code plugins, coliseum-from-grain and pentaphase-structural-architect.

Install in Claude Code

/plugin marketplace add 4444J99/a-i--skills
/plugin install example-skills@a-i-skills

For Codex, Gemini CLI, and direct use, see the installation guide in the README.
